# LearnFlow 使用指南

> 核心定位 · Features · 具体用例。写给"课程在 A 平台、作业在微信群、证书手搓"的讲师 / 知识付费创作者,
> 也是官网改版的素材源(与本 README 同源维护)。

---

## 核心定位

**LearnFlow 是知识付费工作台 + Agent:内容生产 → 组织上架 → 交付 → 运营 → 复盘一个后台管完,外加每天自我体检。它是进阶层单件——你在用 OpenFlow 后长出"课程交付要重运营"的需求时装它;它也不强依赖任何 CMS / CDP,单独成立。**

讲师做线上课通常东拼西凑:课程在 A 平台、作业在微信群、证书用设计工具手搓、学员数据导不出来。LearnFlow 把这条链收进一套台子,开营到结业不出这个门。训练营运营能力全部来自真实开营(R.B.E 训练营即自家案例),不是纸上设计。

它不是又一个小鹅通:轻(PHP 8.3 + JSON 数据层,零框架、零 composer 运行时依赖,一台普通主机就能跑);可无头(REST `/api/v1` + MCP `/mcp` 共 42 个工具,你的 Agent 能替你查数据、改课、出题、发通知,按 read / write / ai 作用域授权);数据可迁移(学员、进度、订单归因在自己手里,可导出可删除);会自我体检(每天自检工程 / 内容 / 运营 / 业务信号,生成改进提案,护栏内自动执行并验证效果)。

## Features(按你将真实用到的顺序)

### 1. 第一天:建课、传课、走完一遍
`php bin/seed.php` 生成管理员与示例课 → 后台建课、传一节视频 → 到学员端 `/courses` 用演示学员报名,走完「学习 → 测验 → 证书」全流程。

### 2. 内容生产:编辑器 + AI 内容工厂
富文本编辑器 + 素材库 + Markdown 导入拆课时;AI 内容工厂出讲义、把资料变成课、写营销文案(朋友圈 / 社群 / 直播脚本 / 口播 / PPT / 邮件),每日额度保险丝防跑飞。

### 3. 组织上架:审批与定时发布
章节课时(图文 / 视频 / HLS / 直播位)、分类标签、中英多语言、课程模板跨课程复用;发布走「编辑提交 → 管理员上架」审批,可定时发布。

### 4. 交付:播放器、测验、证书
断点续播 / 字幕 / 自动连播 / 防盗水印,签名 URL + Range 分段防下载;章节 + 结业测验;可分享、可校验的结业证书;学习笔记与划词标注。

### 5. 训练营:开营到结业的运营台
开营节奏与每日任务、作业提交与讲师 / AI 点评、打卡与连续激励、圈子(问答 / 晒进度 / 点赞评论)、风险学员识别。

### 6. 触达与转化
站内通知 + SMTP 邮件(文案模板可编辑)、免费课时试看、优惠券、推荐码归因、多级分销佣金记录、会员等级(PayFlow 下单即开通)。

### 7. 复盘:漏斗与流失榜
营收 / 客单价 / 转化漏斗(注册→报名→付费→完课→发证)、课时流失榜、题目正确率、来源与推荐分析,CSV 导出;AI 周报替你把结论写好。

### 8. 自我体检 + Agent 接入
每日自检 → 提案 → 分级自治执行(L0–L2 护栏:每日上限 / 按类型上限 / 静默时段)→ 效果验证 → 策略库复利;PWA 可安装 + 微信小程序。

## 具体用例(可直接照抄的实战路径)

### 用例 A · 课程上架与交付(独立讲师)
1. 后台「课程」新建课程 → Markdown 导入拆章节课时,上传视频;
2. 设一节免费试看 + 新客优惠券,提交上架审批;
3. 学员报名后:看课(断点续播)→ 章节测验 → 结业测验 → 自动发可校验证书;
4. 后台看课时流失榜,流失最多的那节下周就改。
**结果**:从写课到发证一个后台;签名下载与防盗水印保护内容资产。

### 用例 B · 训练营运营(14 天实战营)
1. 「训练营」里设开营节奏与每日任务,排直播日程(开播前 24h 自动提醒);
2. 学员每天打卡,连续激励自动算;作业提交后你点评,或让 AI 预审再复核;
3. 圈子里问答、晒进度;风险学员名单每天看一眼,及时私聊拉回;
4. 结营出完课率与证书数据,定下一期改什么。
**结果**:运营动作不再散在微信群;谁哪天掉队一眼可见。

### 用例 C · 完课证书驱动传播(想老带新的讲师)
1. 学员结业自动颁发证书,证书页可分享、可校验真伪;
2. 学员晒图自带课程入口,配合推荐码归因记录来源;
3. 推荐奖励券自动发放,佣金记录在案待结算。
**结果**:结业瞬间变成传播素材,每一单来源说得清。

### 用例 D · 每周复盘(AI 周报)
1. 配置 DeepSeek key(见 `docs/AI-DEEPSEEK.md`);
2. 每周跑 `ai.weekly_report`:营收 / 漏斗 / 流失 / 正确率汇成结论;
3. 把"下周改哪节课、加哪类题"记下来,体检系统在下周期验证效果。
**结果**:复盘从"翻报表"变成"读结论、做决定"。

## 常见问题

**Q:分销佣金能自动结算打款吗?**
分销只做佣金记录 / 归因 / 待结算汇总,不动资金——拼团等资金域归 PayFlow。

**Q:AI 功能必须配 key 吗?**
作业点评 / 出题 / 周报 / 内容工厂需自配 DeepSeek API key;未配置时对应功能不可用,其余功能不受影响。

**Q:视频转码、封面怎么办?**
需主机装好 ffmpeg(`bin/transcode.php` 就绪即用);无内置 DRM,靠签名 URL + 防盗水印。

**Q:向量检索要额外服务吗?**
可插拔 embeddings,未配置自动回退 BM25,检索不中断。

**Q:部署要求高吗?**
PHP 8.3,零框架、零 composer 运行时依赖,一台普通主机就能跑;数据层 MySQL / SQLite 双驱动,运行时数据在 `data/`(服务器为准,永不入 git)。

**Q:小程序能直接上架吗?**
工程已就绪,上架发布需自备微信资质;HLS / 直播经 web-view 打开 H5,未内嵌微信支付。

## 进阶

- **配 PayFlow**:收款交给它——购买即入学、退款撤销权益(已联调);LearnFlow 专心做交付。
- **配 UserLoop**:学习事件实时投递其旅程 / Loop 引擎,报名提醒、召回、复购编排由它承载。
- **配 MFlow**:课程上新等信号经通用 webhook(HMAC)进内容分发。
- **已在用 OpenFlow**:全站官网与内容 CMS 归 OpenFlow,LearnFlow 只管课程交付域。
- **让 Agent 干活**:MCP 客户端连 `/mcp`(JSON-RPC 2.0,42 工具,read / write / ai 三作用域 + 限流 + 审计),出题、点评、周报都能委托。
- **日常运维节奏**:cron 六条——互通投递(15 分钟)、学习提醒(9:00)、备份(3:30,保留 14 份)、直播提醒(每小时)、定时发布(5 分钟)、转码(4:00,需 ffmpeg)。
