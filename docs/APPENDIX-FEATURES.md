# 附录 · 功能总表（每个模块的截图 · 介绍 · 使用说明）

> 按「学员侧 / 讲师管理侧 / Agent 与自动化」组织：学员端 17 页对应仓库根的页面文件，讲师后台 31 页与后台侧栏导航一一对应，Agent 能力对应 `mcp.php` 与 `api/`。
> 每项含：功能介绍（1-2 句，讲用户价值不讲实现）/ 使用说明（怎么开始用）/ 截图。
> 标注 📷 的有真实截图；未标注的为「截图待补」，样式统一不缺位。

LearnFlow 只管一件事：课卖出去之后，把它交付好、运营好。学员走一条路——报名、看课、测验、拿证；讲师守一个后台——内容、教学、运营、系统四区分开，侧栏直达。

---

## 学员侧

学员端是仓库根的一组页面，导航固定四项：课程 / 训练营 / 会员 / 我的学习；证书验证、条款等辅助页在页脚。

#### 课程列表 `学员端 · /courses`

学员逛课的地方：课程卡片带类型、章节数与价格，可按分类筛选；已报名的课直接标出来。

**怎么用**：上线后默认首页即课程列表；后台「分类」里建好分类，课程挂上分类就会出现在筛选里。

📷 ![课程列表](screenshots/01-home.png)

#### 课程详情 `学员端 · /course/{slug}`

大纲、师资、价格、证书说明一页看完；未报名学员从这里进，支持优惠码与邀请码入学，已有权限则直接「继续学习」。

**怎么用**：后台建课时填好简介与大纲即可；免费课时记得勾「试看」，招生页更有说服力。

📷 ![课程详情](screenshots/03-course.png)

#### 学习页 `学员端 · /learn/{slug}`

学员停留最久的页面：播放器（断点续播、字幕、自动连播、防盗水印）+ 课时目录 + 进度 + 笔记 + 资料下载，右侧一栏收纳完毕。

**怎么用**：报名后从课程详情或「我的学习」进入；学员可以课内搜索课时、记笔记（仅自己可见）。

📷 ![学习页](screenshots/05-learn.png)

#### 测验 `学员端 · /quiz/{slug}`

章节测验与结业测验都在线作答、即时判分；单选、多选、判断题型，答错有解析。

**怎么用**：后台「测验」里建题，再把测验挂到章节或课程结尾；结业测验设通过分，通过才有证书。

#### 训练营 `学员端 · /camp` · `/camp/{slug}`

训练营列表与详情：开营节奏、每日任务、打卡日历、圈子入口集中在营页；学员按天推进，不掉队。

**怎么用**：课程类型选「训练营」并设定起止日期；学员报名后从营页进入每日任务。

#### 结业证书 `学员端 · /certificate/{no}` · `/certificate`

完成全部课时并通过结业测验自动签发：证书编号唯一、可公开验证真伪、一键复制分享链接；页脚「证书验证」入口供任何人核验。

**怎么用**：建课时勾选「结业证书」；把分享链接挂到学员的 LinkedIn / 简历，证书就是你的招生广告。

📷 ![结业证书](screenshots/04-certificate.png)

#### 我的学习 `学员端 · /dashboard`

学员自己的书架：在学的课与进度、拿到的证书、学习时长统计；下次该学哪节，进来就知道。

**怎么用**：无需配置；学员登录后导航最后一项即达。

📷 ![我的学习](screenshots/06-dashboard.png)

#### 会员 `学员端 · /membership`

会员等级介绍与开通入口：会员专享课程与专属折扣；在 PayFlow 完成下单后会员自动开通。

**怎么用**：后台「会员」里配置等级与权益；收款交给 PayFlow（学员付款后会员自动开通）。

#### 邀请码入学 `学员端 · /join`

凭邀请码免费入学指定课程/训练营——内测、老学员回馈、社群福利的最短路径。

**怎么用**：后台「邀请码」生成（可限次数与有效期），把码发到目标人群；学员输入即报名。

#### 注册 / 登录 / 找回密码 `学员端 · /login` · `/forgot-password` · `/reset-password`

邮箱注册与登录，支持找回密码；登录有限流保护，密码哈希存储。

**怎么用**：默认开放注册；想邀请制就只发邀请码、不对外公开报名入口。

#### 账户与通知 `学员端 · /account` · `/notifications`

学员改称呼密码、导出或删除自己的数据（合规要求）；站内通知中心集中收报名提醒、作业点评、开课提醒。

**怎么用**：无需配置；邮件通知需在「设置」配好 SMTP。

#### 服务条款 / 隐私政策 `学员端 · /terms` · `/privacy`

法务两件套，内容可在后台「设置」里改；上线前建议过一遍。

**怎么用**：后台 → 设置 → 条款与隐私，编辑保存即生效。

## 讲师管理侧

后台入口即站点根路径（线上为 `nownexts.com/learnflow`），未登录就地显示登录表单。侧栏按「概览 / 内容 / 教学 / 运营 / 系统」分组，页内直达。

#### 看板 `后台 → 概览 · /admin/index.php`

课程、学员、报名、发证四个数字加完课率与学习曲线，交付情况一眼看清；可导出学员 CSV 与风险学员名单。

**怎么用**：登录后台默认落在看板；每天先看「风险学员」，再决定今天找谁私聊。

📷 ![讲师后台看板](screenshots/02-admin.png)

#### 营收 `后台 → 概览 · /admin/analytics.php`

营收、客单价、注册→报名→付费→完课→发证漏斗、课时流失榜、题目正确率、来源与推荐分析，全部 CSV 可导出。

**怎么用**：后台 → 概览 → 营收；先看漏斗哪一环掉得最多，再看流失榜定位到具体课时。

#### 自进化 `后台 → 概览 · /admin/evolution.php`

系统的每日自我体检：工程 / 内容 / 运营 / 业务四类信号自动检查，生成改进提案；你在决定要不要采纳，采纳后系统验证效果。

**怎么用**：后台 → 概览 → 自进化；配合 `php bin/selfcheck.php`（体检）与 `php bin/autonomy.php`（护栏内执行，默认仅提议）。

#### 策略库 `后台 → 概览 · /admin/strategies.php`

自进化沉淀下来的运营策略：什么条件下做什么动作、效果如何，全部留档可复用——运营经验不再跟着人走。

**怎么用**：后台 → 概览 → 策略库；提案被采纳后自动入库，也可以手工录入自己的打法。

#### 课程 `后台 → 内容 · /admin/courses.php`

课程的增删改与上下架：章节课时（图文 / 视频 / HLS / 直播位）、中英双语、课程模板跨课复用、版本历史与恢复、团队批注。

**怎么用**：后台 → 内容 → 课程 → 新建；编辑器支持 Markdown 导入拆课时；发布走「编辑提交 → 管理员上架」。

#### 测验 `后台 → 内容 · /admin/quizzes.php`

题库与测验管理：单选 / 多选 / 判断，设通过分，区分章节测验与结业测验；题目正确率回流营收看板。

**怎么用**：后台 → 内容 → 测验 → 新建；建好后把测验挂进课程大纲对应位置。

#### 分类 / 素材 / 内容库 `后台 → 内容 · /admin/categories.php` · `/admin/media.php` · `/admin/library.php`

分类管课程标签，素材库管图片视频，内容库管可跨课复用的内容块——三处素材各归其位，写课随取随用。

**怎么用**：后台 → 内容 → 对应页上传/新建；编辑器里直接引用。

#### AI 工作台 `后台 → 内容 · /admin/ai.php`

AI 内容工厂：讲义生成课程、资料出大纲、营销文案（朋友圈 / 社群 / 直播脚本 / 口播 / PPT / 邮件）一次生成，DeepSeek 驱动、每日额度保险丝防跑飞。

**怎么用**：先在「设置」配 DeepSeek API key（见 `docs/AI-DEEPSEEK.md`）；后台 → 内容 → AI 工作台选一种生成流，产出即草稿，改完再用。

#### 排期 `后台 → 教学 · /admin/schedule.php`

开营节奏与直播课时排期：哪天开营、哪天直播、开播前 24 小时自动提醒，一张表排完。

**怎么用**：后台 → 教学 → 排期；配合 `php bin/live-remind.php`（提醒）按 cron 定时跑。

#### 作业 `后台 → 教学 · /admin/assignments.php`

作业提交、批改与点评记录：学员交作业，你批改，AI 先给一遍初评；点评自动通知学员。

**怎么用**：课时类型选「作业」；后台 → 教学 → 作业看待批列表，AI 点评后复核即可发布。

#### 学员 `后台 → 教学 · /admin/students.php`

学员档案与分组：报名来源、进度、学习时长、笔记与作业全在一人一册；支持分组运营与数据导出/删除（合规）。

**怎么用**：后台 → 教学 → 学员；搜索邮箱定位学员，分组后可按组发通知。

#### 邀请码 `后台 → 教学 · /admin/invites.php`

生成邀请码（限课程、限次数、限有效期），学员凭码免费入学——内测与社群福利的最短路径。

**怎么用**：后台 → 教学 → 邀请码 → 新建；把码发出去，核销情况列表可见。

#### 证书 `后台 → 教学 · /admin/certificates.php`

全部已发证书的台账：编号、学员、课程、签发与校验状态；可撤销（撤销后公开验证即显示失效）。

**怎么用**：无需手工签发——学员达标自动发；这一页只做管理与撤销。

#### 圈子 `后台 → 教学 · /admin/community.php`

学员社区：问答、晒进度、点赞评论都在里面；讲师可置顶、回帖、删除违规内容，风险发言有审核。

**怎么用**：课程开启圈子后学员端自动出现入口；后台此页做管理。

#### 通知与文案模板 `后台 → 运营 · /admin/notify.php` · `/admin/templates.php`

站内通知 + SMTP 邮件双通道：报名成功、开课提醒、作业点评全部自动送达；每类通知的文案模板可改，带变量占位。

**怎么用**：设置里配好 SMTP；后台 → 运营 → 文案模板按场景改文案，通知页看发送记录。

#### 营销 `后台 → 运营 · /admin/marketing.php`

优惠券与推荐奖励：创建优惠券（额度/有效期）、查看推荐归因与积分活动；转化动作不再靠发朋友圈截图。

**怎么用**：后台 → 运营 → 营销；券码学员在课程详情页输入即用。

#### 会员 `后台 → 运营 · /admin/membership.php`

会员等级与权益配置：哪些课程会员专享、折扣多少；学员在 PayFlow 下单后会员自动开通。

**怎么用**：后台 → 运营 → 会员配置等级；权益生效走「members_only」课程标记。

#### 分销佣金 `后台 → 运营 · /admin/commissions.php`

推荐码归因与多级分销的佣金记录、待结算汇总——只记账不动钱，实际打款由 PayFlow / 人工流程完成。

**怎么用**：后台 → 运营 → 分销佣金；学员分享带推荐码的链接即自动归因。

#### API 密钥 `后台 → 系统 · /admin/apikeys.php`

给 Agent 与外部系统发钥匙：按 read / write / ai 三档作用域授权，带限流与调用审计；REST `/api/v1` 与 MCP `/mcp` 双入口通用。

**怎么用**：后台 → 系统 → API 密钥 → 新建，按需勾作用域；接入方式见 [API-MCP.md](API-MCP.md)。

#### 审计与账号 `后台 → 系统 · /admin/audit.php` · `/admin/users.php`

后台所有敏感操作留痕（谁在什么时候做了什么）；团队成员账号管理：管理员 / 编辑 / 只读三角色，敏感页仅管理员可见。

**怎么用**：后台 → 系统 → 审计查操作流水；账号页增减成员并分配角色。

#### 设置 `后台 → 系统 · /admin/settings.php`

站点名、站点地址、SMTP、DeepSeek key、条款隐私、备份策略集中在此；自动备份与轮转默认开启。

**怎么用**：上线第一件事进设置页过一遍；备份文件按策略落盘在 `data/`。

## Agent 与自动化

把重复劳动交给机器：对外的接口，对内的定时脚本。

#### MCP 与 REST API `入口 · /mcp` · `/api/v1`

42 个工具按 read / write / ai 三档授权：只读查课查学员，写入建课发通知，AI 出题批作业写周报。MCP 走 JSON-RPC 2.0（initialize / tools/list / tools/call），REST 直接调；统一限流 + 审计。

**怎么用**：后台发一把 API Key → MCP 客户端连 `/mcp` 或直接调 `/api/v1`；工具清单见 [API-MCP.md](API-MCP.md)。

#### 互通事件队列 `脚本 · bin/drain.php`

报名、完课、发证等学习事件实时投递给 UserLoop / MFlow 等矩阵产品（HMAC 签名）；网络失败自动排队重试，`drain.php` 可手动清队列。

**怎么用**：cron 定时跑即可；对接哪些产品在「设置」里配目标与密钥。

#### 定时任务族 `脚本 · bin/{publish,remind,live-remind,backup}.php`

定时发布（到点自动上架）、课前提醒、直播开播前 24 小时提醒、自动备份与轮转——跑起来后后台不需要人守。

**怎么用**：按 [DEPLOY.md](DEPLOY.md) 把四个脚本挂上 cron；`php bin/transcode.php`（视频转码/封面）需主机装好 ffmpeg。

#### 自我体检与自治 `脚本 · bin/selfcheck.php` · `bin/autonomy.php`

每天自检工程 / 内容 / 运营 / 业务信号，生成改进提案；`autonomy.php` 在护栏内执行（L0–L2：每日上限 / 按类型上限 / 静默时段，默认仅提议），执行后验证效果并沉淀策略库。

**怎么用**：cron 跑 `selfcheck.php`；想放开手脚先在「自进化」页把分级与上限调清楚。

#### PWA 与小程序 `入口 · manifest · miniprogram/`

学员端可安装到手机桌面（PWA，离线壳 + 推送就绪）；微信小程序工程在 `miniprogram/`，上架需自备微信资质。

**怎么用**：PWA 开箱即用（HTTPS 环境下浏览器会提示安装）；小程序按 `docs/MINIPROGRAM.md` 编译上传。
